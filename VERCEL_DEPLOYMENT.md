# Deploying TruthWeave AI to Vercel

This project is fully configured for zero-configuration, one-click deployment on **Vercel** with both the React (Vite) frontend and FastAPI (Python) backend running seamlessly.

---

## 🚀 Quick Deployment Guide

### Option 1: Deploy via Vercel Dashboard (Recommended)

1. Push this codebase to your GitHub repository (`meghaaa111/truthweave`).
2. Go to [vercel.com/new](https://vercel.com/new) and log in.
3. Import your `truthweave` repository into Vercel.
4. Vercel will automatically detect the Vite build settings (`npm run build`, `dist` directory).
5. **Configure Environment Variables** in the Vercel deploy screen (see table below).
6. Click **Deploy**.

---

### Option 2: Deploy via Vercel CLI

1. Install Vercel CLI globally:
   ```bash
   npm install -g vercel
   ```
2. Run the deployment command from the project root:
   ```bash
   vercel
   ```
3. Follow the CLI prompts (accept defaults).
4. For production deployment, run:
   ```bash
   vercel --prod
   ```

## 🔑 Environment Variables Configuration

Set these environment variables in your **Vercel Project Settings → Environment Variables**:

| Variable Name | Required | Default / Example | Description |
|---|---|---|---|
| `DEMO_MODE` | No | `true` | Set `true` for mock testing, or `false` to use live AI APIs. |
| `GEMINI_API_KEY` | Optional | `AIzaSy...` | Google Gemini API key for claim analysis. |
| `HUGGING_FACE_TOKEN` | Optional | `hf_...` | Hugging Face API token for OCR image extraction. |

## 🛠️ Project Architecture on Vercel

```
 TruthSeeker/
 ├── api/index.py         # Serverless Python entry point for FastAPI backend
 ├── vercel.json          # Rewrites /api/* to api/index.py & handles SPA routes
 ├── requirements.txt     # Python dependencies installed by Vercel
 ├── src/                 # React + TypeScript frontend
 └── dist/                # Static frontend output generated by `npm run build`
```

- **Frontend Routes**: Managed by React Router SPA (`/(.*)` rewrites to `/index.html`).
- **Backend API Routes**: Handled by Python Serverless Functions (`/api/*` rewrites to `api/index.py`).
